# taskFlow
Gerenciador de tarefas simples, feito só com HTML, CSS e JavaScript.

## Por que construí
Praticar JavaScript puro: manipulação do DOM, eventos e localStorage.

## Versão 1
- Adicionar, concluir e excluir tarefas
- Três colunas: A fazer, Fazendo e Feito
- Salvar as tarefas no navegador (localStorage)
- Barra de progresso

## Ideias para depois
- Arrastar e soltar tarefas entre colunas
- Editar, buscar e filtrar tarefas
- Atalhos de teclado, exportar/importar em JSON e tema escuro
